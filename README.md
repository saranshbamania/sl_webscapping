# sl_webscapping
webcapping code for fights
This project aims to develop a web scraping tool to extract real-time flight price data from various travel websites for analysis and trend prediction in the airline industry.
Objectives include collecting structured flight price data, for The five busiest airports in India and 10 busiest airports in the world as of 2023 along with storing it in a centralized database ,and  analyzing trends to provide insights for travelers
